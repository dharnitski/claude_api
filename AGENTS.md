# AGENTS.md

Guidance for AI coding agents working in this repository.

This project is in its initial state. As code, conventions, and tooling are
added, update this file to reflect build/test commands and any repo-specific
practices agents should follow.

## Vendor-agnostic artifacts

Keep all artifacts produced in this repo (commit messages, PR descriptions,
code comments, docs) vendor-agnostic. Do not add AI-tool attribution such as
`Co-Authored-By: Claude ...`, "Generated with ..." footers, or similar
tool-specific credits.
